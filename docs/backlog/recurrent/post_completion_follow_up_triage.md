# Recurrent: post-completion follow-up triage

## Metadata
- Created: 2026-07-12
- Status: Recurrent
- Completed: N/A (runs repeatedly)

## Purpose
After completing an item, preserve residual risks, open questions, and
insights as proposed items or notes instead of losing them with the close.

## Run conditions
Whenever an item moves to completed/ or deprecated/.

## Checklist
- [ ] Completion report appended before the move.
- [ ] Residual risks/ideas captured (new proposed item or note in overview).
- [ ] Overview ledger row added (original path, final path, dates, outcome,
      key validation).

## Expected output
No silent loss of follow-up signal.

## Non-goals
Reopening closed decisions without new evidence.
